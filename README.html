AgentCiCi 开发与管理 Skill

阅读摘要

这是一个给 Codex 等 AI 智能体使用的 Skill。用户不需要手动运行管理脚本，只需要用自然语言说明目标。当前版本为 1.8.2。

AI应用开发只在 applications/<appCode>/ 进行，不需要平台backend/frontend/deploy源码。每个应用独立维护清单、源码与发布产物；CloudCC资源集中在 cloudcc/，类为 cloudcc/backend/classes/。项目根目录共用配置和CRM缓存，适配器临时链接后在应用cloudcc工程内操作，不创建根backend映射。查看目录规则。已有项目保留其结构，不自动迁移。

AI App七阶段流程涵盖Web、对象/字段、自定义类，以及智能体、技能、知识库和MCP关联；AgentCiCi与CRM开发凭据分别配置。知识库开发者管理与组织应用发布需部署对应后端并授予scope。

Web 使用原生 HTML、CSS、JavaScript；业务按需采用 Web → 自定义类 → 自定义对象、Web → Agent（智能体）两条调用链。

安装 Skill

把仓库地址发给 Codex，然后说：

请从 https://github.com/CloudCCAI/cc-aidev-agentcici-expert 的仓库根目录安装技能，安装目录名指定为 cc-aidev-agentcici-expert；已有安装按当前工具的升级流程处理，保留环境配置。

使用 Codex 的 skill-installer 首次安装时，向其 scripts/install-skill-from-github.py 传入 --repo CloudCCAI/cc-aidev-agentcici-expert --path . --name cc-aidev-agentcici-expert。执行时使用安装器的实际绝对路径；目标已存在时不要直接重复首次安装命令，也不要清空配置。其他AI工具同样保留该技能目录名。仓库名与技能名统一为cc-aidev-agentcici-expert，安装时仍显式指定目录名。

安装后可以说：

使用 $cc-aidev-agentcici-expert 查看当前组织的智能体。

登录 AgentCiCi

  1. 在 AgentCiCi 管理后台点击“复制 AI 登录信息”。
  2. 把完整内容粘贴给 Codex。
  3. 说明需要登录并保存状态。
这是 AgentCiCi 后台复制的 AI 登录信息，请帮我登录并记住登录状态。

Skill 会先验证凭据，成功后将解码后的地址、Client ID 和 Secret 直接保存到项目 cloudcc-agentcici.config.json。通过 use 管理多个环境，文件自动加入 .gitignore，POSIX 权限设为 0600。Token 不落盘；旧版登录需要重新 login。

查看我是否已经登录 AgentCiCi。
清除这台电脑上保存的 AgentCiCi 登录信息。
不要把登录信息发到公开对话、工单或代码仓库。Skill 不会在回答中回显 Secret 或 Token。

查看和管理资源

列出当前组织的所有智能体，显示 ID、名称和发布状态。
查看这个智能体的详情，以及它关联的技能、知识库和工具。
创建一个用于生成客户拜访总结的智能体。先跟我确认名称、说明和需要关联的资源，再创建。
把“客户资料检索”技能关联到这个智能体，保留它现有的其他关联。
编译这个智能体；成功后把新版本号告诉我，先不发布。

Skill 会在更新前读取当前资源，只更改用户已确认的内容。

导入和导出资源包

把智能体“客户助手”以 AgentCiCi 原生包导出到当前项目的 exports 目录。
用这个原生智能体包和这两个技能包准备一个 AI 应用发布包，先检查依赖映射，不要提交。

开发 AI Web 应用

开发一个“客户摘要”AI Web 应用。它在 CloudCC 里打开，使用当前登录组织的 AgentCiCi 配置。先准备可本地验证的前端和应用清单，不要提交发布申请。

如果用户没有特别说明，Web 应用默认使用 CloudCC 脚本菜单触发，并在菜单内容区展示。

这个应用不要使用默认菜单，改为全局浮点入口，打开后默认显示在右侧。

准备和提交发布申请

检查这个 AI 应用还缺哪些发布信息，只问我尚未确认的必填项。
构建并校验这个 AI 应用的发布申请包。完成后告诉我实际清单和产物路径，不要上传。
把刚才校验通过的发布申请包提交到 AgentCiCi，然后返回申请 ID 和状态。

准备发布包、上传申请、创建草稿和平台上架是不同阶段。平台上架仍由平台管理员执行。

Skill 的操作原则

  • 只读任务不会修改平台资源。
  • 修改前先读取当前对象。
  • 不擅自绑定其他资源或凭据。
  • 删除前确认精确目标。
  • 不暴露 Secret、Token 或 API Key。
